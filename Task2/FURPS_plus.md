# FURPS+

| Код    | Требования                                                                                                 | Комментарий                                                                                                     |
|--------|------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------|
| **F**  | **Функциональные (Functionality)**                                                                         |                                                                                                                 |
| F1     | Сайт должен показывать актуальный перечень депозитных продуктов и ставок                                   |                                                                                                                 |
| F2     | Сайт должен иметь возможность принимать заявку на депозит                                                  |                                                                                                                 |
| F3     | Сайт должен создавать обращение в системе кол-центра при принятии заявки                                   |                                                                                                                 |
| F4     | Интернет-банк должен должен показывать персонализированный перечень депозитных продуктов и ставок          |                                                                                                                 |
| F5     | Интернет-банк должен иметь возможность принимать заявку на депозит                                         |                                                                                                                 |
| F6     | Интернет-банк должен подтверджать операцию подачи заявки с помощью СМС-OTP                                 |                                                                                                                 |
| F7     | АБС должна иметь возможность подтверждать условия депозита и отправлять по результатам СМС-уведомление     |                                                                                                                 |
| F8     | АБС должна предоставлять возможность управлять текущими актуальными ставками сотрудникам отделов бэк-офиса | Требование поддержки информации в актуальном состоянии, предпочтительно иметь разграниченный доступ для отделов |
| **U**  | **Удобство использования (Usability)**                                                                     |                                                                                                                 |
| U1     | Интерфейсы сайта и интернет-банка соответствуют корпоративной дизайн-системе                               |                                                                                                                 |
| U2     | Время отклика любой операции клиента < 300 мс                                                              |                                                                                                                 |
| U3     | Скорость доставки исходящего СМС-сообщения < 1мин                                                          | Требование UX по СМС-операциям                                                                                  |
| **R**  | **Надёжность (Reliability)**                                                                               |                                                                                                                 |
| R1     | Доступность всех сервисов системы (сайт, интернет-банк, СМС-шлюз) - 99.9%, режим 24/7                      |                                                                                                                 |
| R2     | Переключение интернет-банка на резервный ЦОД без потери заявок                                             |                                                                                                                 |
| R3     | Использование TLS 1.2+ для сайта и интернет-банка                                                          |                                                                                                                 |
| **P**  | **Производительность (Performance)**                                                                       |                                                                                                                 |
| P1     | Поддержка горизонтального масштабирования интернет-банка; равномерное распределение нагрузки между ЦОД     |                                                                                                                 |
| P2     | Минимизация нагрузки на БД АБС                                                                             |                                                                                                                 |
| P3     | Обработка пиковых заявок без деградации SLA (< 300 мс)                                                     | Планируется рост онлайн-клиентов                                                                                |
| **S**  | **Поддерживаемость (Supportability)**                                                                      |                                                                                                                 |
| S1     | Использовать существующие технологии: .NET / Java / MS SQL / Oracle / React                                |                                                                                                                 |
| S2     | Постепенный переход на микросервисную архитектуру                                                          |                                                                                                                 |
| S3     | Документация API и процессов (OpenAPI, UML, ADR)                                                           |                                                                                                                 |
| **+R** | **+ Ограничения (Restrictions)**                                                                           |                                                                                                                 |
| +R1    | Личная идентификация клиента для новых клиентов                                                            |                                                                                                                 |
| +R2    | Разграничение доступа: сотрудники депозитов и кредитов не видят данные друг друга                          |                                                                                                                 |
| +R3    | АБС масштабируется только вертикально                                                                      |                                                                                                                 |
| +R4    | Текущиая версия стека .NET несовместима с Kafka                                                            |                                                                                                                 |
